# 🧮 Python Calculator

A simple command-line calculator built using Python.

## 📌 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🟰 Modulus
- 🔢 Power
- √ Square Root
- ❌ Handles division by zero
- ⚠️ Handles negative square root input

## 🛠 Technologies Used

- Python 3
- Math Module

## ▶️ How to Run

```bash
python calculator.py
```
